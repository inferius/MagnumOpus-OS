Jak by to vypadalo v API

Ve všech variantách aplikace menu jen deklaruje jako data a systém ho kreslí (v titulku, v horní liště, v paletě, ve čtečce obrazovky). Položka menu je akce z API akcí, takže stejnou věc zavolá klik v menu, zkratka, paleta, shell i agent AI (agent jen s oprávněním a viditelně).

// Rust (libs/ui), menu je soucast popisu okna; posila se kompozitoru jako data.
menu([
  group("Soubor", [
    item("file.new").label("Nový").shortcut("Ctrl+N").icon("file-plus"),
    item("file.open").label("Otevřít...").shortcut("Ctrl+O"),
    recent("file.recent"),                        // systém plní nedávné soubory
    separator(),
    item("file.export").label("Exportovat").submenu([
      item("file.export.pdf").label("PDF").icon("app-pdf"),
      item("file.export.html").label("HTML"),
    ]),
  ]),
  group("Úpravy", [
    role(Role::Undo), role(Role::Redo),           // jednotné texty, zkratky a ikony v celém systému
    separator(),
    role(Role::Cut), role(Role::Copy), role(Role::Paste),
    item("edit.paste_table").label("Vložit jako tabulku").enabled(self.clip_is_table),
    separator(),
    item("view.wrap").label("Zalamovat řádky").checked(self.wrap),   // zaškrtávací
    radio_group("view.mode", ["Psaní", "Náhled", "Rozdělit"], self.mode),
  ]),
]).primary(["file", "edit", "view"])               // co se vejde do řádku menu; zbytek v tlačítku menu

// Role (Undo, Redo, Cut, Copy, Paste, SelectAll, Find, Replace, Preferences, Close, Quit, About):
// systém dodá text v jazyce uživatele, zkratku podle rozložení a ikonu; aplikace jen řekne, že roli umí.
// Stav (enabled, checked, label) se mění zprávou MENU_UPDATE, ne překreslením celého menu.
// Zkratky: systém hlídá kolize se systémovými zkratkami a ukáže je v paletě.
