# Plocha a lišta

**Lišta** je dole na obrazovce. Zleva doprava:

| Část | Co dělá |
|---|---|
| Spouštěč (ikona mřížky) | seznam aplikací; kliknutím aplikaci spustíte |
| Aplikace | ikony aplikací; tečka pod ikonou = běží, delší čárka = okno je aktivní. Klik na neběžící aplikaci ji spustí, na běžící ji přepne do popředí |
| Úlohy | počet běžících úloh; když něco dělá agent AI, je u čísla korálový štítek |
| Síť, zvuk | skutečný stav sítě a hlasitosti; kliknutím zobrazíte podrobnosti |
| Oznámení | zatím jen „Žádná oznámení“ (centrum oznámení *připravujeme*) |
| Hodiny | čas a datum |

Okénko s podrobnostmi zavřete klávesou Esc, kliknutím jinam nebo druhým
kliknutím na stejnou ikonu.

Když program ovládá klávesnici nebo myš místo vás (automatizace), ukáže
lišta štítek **„Vstup ovládá automat“**.

Wi-Fi a změnu polohy lišty *připravujeme*.
