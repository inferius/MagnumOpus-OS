# Klávesové zkratky

Klávesa **Super** je ta s logem (na klávesnicích pro Windows s logem
Windows).

| Zkratka | Co udělá |
|---|---|
| `Ctrl+K` nebo `Super+K` | otevře [paletu příkazů](paleta.md) |
| `Super+Shift+F` | zapne nebo ukončí celou obrazovku |
| `Ctrl+Alt+Shift+S` nebo `Print Screen` | diagnostický snímek |
| `Ctrl+Alt+Delete` | bezpečná obrazovka |
| `Esc` | zavře paletu, nabídku nebo okénko z lišty |

## V dialozích

| Zkratka | Co udělá |
|---|---|
| `Tab`, šipky | jiná volba |
| `Enter` | potvrdit |
| `Esc` | odmítnout |

## V terminálu

| Zkratka | Co udělá |
|---|---|
| `Tab` | doplnit |
| `↑` `↓` | historie příkazů |
| `Ctrl+C` | zastavit příkaz |
| `Ctrl+L` | sbalit staré bloky |
| `Ctrl+T` | panel úloh |

Přepínání oken `Alt+Tab`, přichycení oken `Super+šipky` a čtečku
obrazovky *připravujeme*.
