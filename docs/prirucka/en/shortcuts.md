# Keyboard shortcuts

The **Super** key is the one with the logo (on Windows keyboards, the one
with the Windows logo).

| Shortcut | What it does |
|---|---|
| `Ctrl+K` or `Super+K` | opens the [Command palette](palette.md) |
| `Super+Shift+F` | turns full screen on or off |
| `Ctrl+Alt+Shift+S` or `Print Screen` | diagnostic snapshot |
| `Ctrl+Alt+Delete` | secure screen |
| `Esc` | closes the palette, a menu or a box from the bar |

## In dialogs

| Shortcut | What it does |
|---|---|
| `Tab`, arrows | another choice |
| `Enter` | confirm |
| `Esc` | decline |

## In the terminal

| Shortcut | What it does |
|---|---|
| `Tab` | complete |
| `↑` `↓` | command history |
| `Ctrl+C` | stop a command |
| `Ctrl+L` | collapse old blocks |
| `Ctrl+T` | task panel |

Window switching with `Alt+Tab`, window snapping with `Super+arrows` and a
screen reader are *coming soon*.
