# Apps

## Starting an app

- Click the app icon in the **bar** or in the **launcher** (the grid icon
  on the left).
- Or open the **palette** (`Ctrl+K`) and type the name of the app.

When the app is already running, clicking only brings it to the front.

## Apps in the system

| App | What it is for |
|---|---|
| Terminal | commands and working with files, see [Terminal for beginners](terminal.md) |
| Task manager | what is running right now, who started it, how much it uses; with sample data for now |
| Demo | a sample app with controls |

## More windows

**Terminal** supports several sessions (tabs in the window title). A session
belongs to the system: when you close the terminal window, a running command
finishes anyway.

More windows of the same app from the bar and new apps (Files, Settings,
Editor, Browser) are *coming soon*.
