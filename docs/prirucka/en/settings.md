# Settings

The Settings app is *coming soon*. For now you can change:

| What | How |
|---|---|
| Theme (light, dark, high contrast) | for now only through a system command, a switch in Settings is *coming soon* |
| Diagnostic snapshot | the file `/system/log/snimek.conf` |
| Detail level of records (logs) | the `loglevel` command in the terminal |

Security profiles (Standard, Strict, Relaxed), the position of the bar and
the font size are *coming soon*.
