# Desktop and bar

The **bar** is at the bottom of the screen. From left to right:

| Part | What it does |
|---|---|
| Launcher (grid icon) | a list of apps; click an app to start it |
| Apps | app icons; a dot under an icon = running, a longer dash = the window is active. Clicking an app that is not running starts it, clicking a running one brings it to the front |
| Tasks | the number of running tasks; when an AI agent is doing something, a coral tag appears next to the number |
| Network, sound | the real state of the network and the volume; click to see details |
| Notifications | only "No notifications" for now (a notification center is *coming soon*) |
| Clock | time and date |

Close the details box with the Esc key, by clicking elsewhere, or by
clicking the same icon a second time.

When a program controls the keyboard or mouse instead of you (automation),
the bar shows a tag **"Input controlled by automation"**.

Wi-Fi and changing the position of the bar are *coming soon*.
